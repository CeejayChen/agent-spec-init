# AGENTS.md — Archived Agent Notes

Archived Agent Notes are frozen historical snapshots. They are never current authority.

## Rules

- Never edit, translate, reformat, update, move, or delete a sealed artifact.
- Never treat archived notes as authority for current behavior.
- Active prose may still link into an archived note when it intentionally cites history.
- Only `implemented/` notes can be archived.
- The archival change may only: relocate the complete file, insert `Archived: YYYY-MM-DD` below `Status: implemented`, and repair or delete inbound links.
