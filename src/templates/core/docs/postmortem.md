# Postmortems

Incident stories live here. A postmortem records the incident sequence, the evidence, the causal chain, the impact, and the prevention that shipped.

## Adding a postmortem

1. State the impact in user-visible terms and when the incident started.
2. Reconstruct the sequence from logs and commits, with a timestamp per step.
3. Separate the trigger from the conditions that let it spread.
4. Name each prevention and the check that would catch a recurrence; link the Agent Note that records a lasting decision.
